# Medicine Shop Game

A 2D medicine shop management game where players diagnose patients, learn herbal properties, compound prescriptions, gather herbs, and grow a small shop while uncovering problems in the town's medical system.

## Current Status

This project is currently in the early design stage.

The current focus is on defining:

- Core gameplay loop
- Medicine compounding system
- Game systems
- Story and world direction

## Core Idea

The game is not just about collecting herbs and selling medicine.

Players will:

- Diagnose patients through symptoms
- Learn herbal properties such as cold, hot, warm, cool, and neutral
- Combine herbs while considering synergy and conflicts
- Prepare medicine or pills for different cases
- Grow herbs in the medicine field
- Gather rare herbs from the mountains
- Upgrade the medicine shop
- Discover the truth behind fake medicine and unusual illnesses in town

## Planned Features

- Patient diagnosis system
- Herbal property and prescription system
- Herb farming
- Mountain herb gathering
- Medicine compounding
- Pill refining
- Shop management
- Town NPCs and story events
- Multiple development directions for the medicine shop
